# returns-page-project
BA practice project: requirements, user stories and prototype for an online returns page

Status: prototype tested

Git tracks every version of a project's files, and GitHub stores them online so teams can share them. A repository is the project folder with its history. I created a repo for my returns page project and uploaded my BRD, FRD, user stories and prototype screenshots, then edited the README to show another commit. For a BA, this means requirement changes are traceable and the whole team works from the latest files.
